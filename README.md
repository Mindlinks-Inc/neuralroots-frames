# neuralroots-frames

Hero scroll-animation frames for the Neural Roots website (162 JPGs, `frame_001.jpg` → `frame_162.jpg`).

Served over the free jsDelivr CDN:

```
https://cdn.jsdelivr.net/gh/<your-username>/neuralroots-frames@main/frames/frame_001.jpg
```

Base URL for the hero script:

```
https://cdn.jsdelivr.net/gh/<your-username>/neuralroots-frames@main/frames/
```

To refresh the frames later, replace the files and push, then bump the tag in the URL (e.g. `@v2`) so the CDN serves the new ones immediately.
